🎵 Telegram VC Music Bot

Simple and powerful Telegram Voice Chat Music Bot built with Pyrogram & PyTgCalls.

---

🚀 Features

- ▶️ Play music from YouTube
- ⏸ Pause / Resume
- ⏹ Stop streaming
- 🎧 Stream in Voice Chat (VC)
- 🤖 Easy to setup

---

📦 Requirements

- Python 3.9+
- FFmpeg installed
- Telegram API ID & API Hash
- Bot Token (from @BotFather)
- Session String (User account)

---

⚙️ Setup

1. Clone Repo

git clone https://github.com/nainglin2005716-lang/My-music-bot/edit/main/README.md

2. Install Dependencies

pip install -r requirements.txt

3. Create .env file

API_ID=YOUR_API_ID
API_HASH=YOUR_API_HASH
BOT_TOKEN=YOUR_BOT_TOKEN
SESSION_STRING=YOUR_SESSION_STRING

---

▶️ Run Bot

python main.py

---

🎮 Commands

- "/play <youtube link>" → Play music
- "/pause" → Pause music
- "/resume" → Resume music
- "/stop" → Stop music

---

⚠️ Notes

- Bot must be admin in group
- Voice chat must be started
- Never share your API / Session String
